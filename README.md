### Featured Projects

<details open>
<summary><b>PHOENIX — Intelligent MANET Routing Framework</b></summary>
<br/>

**Problem**
Mobile Ad-hoc Networks (MANETs) suffer from unstable routing under node mobility and congestion — traditional protocols like AODV/AOMDV adapt poorly to dynamic topology changes.

**Approach**
A modular routing framework layering reinforcement learning and optimization techniques on top of established MANET protocols, using mobility prediction and a computed Network Health Index to inform routing decisions in real time.

| | |
|---|---|
| **Stack** | `C++` `NS-3` `DQN` `Ant Colony Optimization` |
| **Engineering Scope** | AODV/AOMDV baseline, adaptive routing layer, mobility prediction, congestion-aware path selection, multi-seed experiment harness with CSV result generation |
| **Evaluation** | Reproducible multi-seed simulation runs designed for PDR, throughput, delay, and overhead comparison against baseline protocols |
| **Repository** | [github.com/HITESHVERMA01/PHOENIX-MANET](https://github.com/HITESHVERMA01/PHOENIX-MANET) |

</details>

<details open>
<summary><b>IR2RGB — Satellite Image Enhancement & Reconstruction</b></summary>
<br/>

**Problem**
Infrared satellite imagery often needs to be reconstructed into usable RGB-equivalent output with enhanced clarity for downstream remote-sensing analysis.

**Approach**
An EDSR-based super-resolution pipeline (×2) combined with CLAHE and adaptive sharpening for contrast and detail recovery, built with a team (ASTRAVISION) as an applied computer vision + remote sensing project.

| | |
|---|---|
| **Stack** | `Python` `EDSR` `OpenCV` `CLAHE` |
| **Engineering Scope** | Super-resolution reconstruction, contrast-limited adaptive histogram equalization, adaptive sharpening pipeline |
| **Evaluation** | PSNR ≈ 33.94 dB · SSIM ≈ 0.928 · MAE ≈ 0.0153 |
| **Repository** | [github.com/CodeXEaters/IR2RGB](https://github.com/CodeXEaters/IR2RGB) |

</details>
